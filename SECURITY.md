# Security policy

Report suspected vulnerabilities privately to the repository owner. Do not open a public issue containing credentials, receipts, tokens, personal payloads or exploit details. The repository contains bounded authentication, storage, transport and synchronization components, but production deployment and general package distribution remain held, and purchase/provider breadth is not implemented. Use only explicitly composed adapters whose documented security and acceptance gates pass for the exact host and artifact. Never commit `.env`, keys, certificates or service credentials.
